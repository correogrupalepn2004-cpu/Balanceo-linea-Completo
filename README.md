# Plataforma MES · EPN
Estudio de tiempos (Westinghouse + OIT), cursograma ASME, teoría de restricciones y balanceo COMSOAL.

```
pip install -r requirements.txt
streamlit run app.py
```
Despliegue: sube `app.py`, `requirements.txt` y `.streamlit/config.toml` a GitHub y conéctalo en share.streamlit.io.
